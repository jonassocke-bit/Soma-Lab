Einmalig: Anny→SOMA Identity-Pack bauen

v0.4.0 wirft die bestehende SOMA-Architektur nicht weg. GitHub Actions startet einmalig das gepinnte offizielle Anny v0.6, erzeugt 216 native Adult-Shape-Anker direkt auf SOMA-Topologie und committed nur den kompakten Browser-Pack.

  1. Die Dateien aus SOMA_BROWSER_POC_V0.4.0.zip zuerst ins bestehende Soma-Lab-Repo hochladen. Die vorhandene soma_current_rig_pack_v0026.npz unbedingt behalten.
  2. GitHub → Actions → New workflow → set up a workflow yourself.
  3. Standardinhalt durch den Workflow unten ersetzen. Dateiname z. B. build-anny-soma-pack.yml. Committen.
  4. Workflow Build Anny SOMA Identity Pack öffnen → Run workflow.
  5. Nach Erfolg liegen anny_soma_identity_grid_v060.npz und .json im Repo. Dann Soma-Lab neu laden → Punkt 3A.
