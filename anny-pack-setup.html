Einmalig: Anny/SOMA Engine v3 bauen

Warum diesmal wirklich ein Action-Lauf nötig ist: v0.5.21 braucht zusätzliche offizielle Anny-Rig-Daten. Der bisherige v2-Pack enthält nur die morphbare Oberfläche, aber nicht Annys shape-abhängige SOMA-Bone-Heads, Bone-Orientierungen und Skinweights.

  1. Den kompletten v0.5.21-Inhalt ins Repo Soma-Lab hochladen.
  2. ANNY_PACK_WORKFLOW.yml als .github/workflows/build-anny-soma-engine-v3.yml speichern.
  3. GitHub → Actions → Build Anny SOMA Engine v3 → Run workflow.
  4. Warten, bis der Lauf grün ist. Er commitet die neuen ..._rigv3.npz-Packs automatisch.
  5. GitHub Pages neu laden. Beim ersten Öffnen werden die neuen Packs einmal geladen und danach persistent gecacht.

Der Browser führt zusätzlich zwei offizielle Anny-Rest-Rig-Paritätsfixtures aus. Wenn die mathematische Rekonstruktion nicht passt, wird der neue Morph-Pfad absichtlich nicht freigeschaltet.
