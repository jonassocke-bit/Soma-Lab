Einmalig: Anny/SOMA Engine v2 bauen

Was dieser eine Workflow macht

Er erneuert den bestehenden SOMA-Rig-Pack um echte 18.056×122 Mid-Skinweights und erzeugt anschließend zwei exakte Anny-Browser-Packs: Low (4.505 Vertices) und Mid (18.056 Vertices) mit allen nativen Phänotyp- und lokalen Blendshapes.

  1. Zuerst alle Dateien aus SOMA_BROWSER_POC_V0.5.0.zip ins bestehende Soma-Lab-Repo hochladen/ersetzen. Die vorhandenen alten NPZ-Dateien dürfen bleiben.
  2. GitHub → Actions → New workflow → set up a workflow yourself.
  3. Dateiname z. B. build-anny-soma-engine-v2.yml.
  4. Standardinhalt löschen und den Workflow unten einsetzen. Committen.
  5. Actions → Build Anny SOMA Engine v2 → Run workflow.
  6. Nach grünem Lauf enthält das Repo zusätzlich anny_soma_engine_low_v060.npz und anny_soma_engine_mid_v060.npz; der vorhandene SOMA-Rig-Pack wurde zugleich auf v2 erweitert.
  7. Soma-Lab neu laden → Shape → Current Rig-Pack → Expanded 122 → Anny Engine Low. Mid wird erst beim ersten Antippen geladen und danach persistent gecacht.
