Pose Oracle – nur wenn Schritt 2 in Sammy fertig ist

Diese Seite ist absichtlich linear. Keine anderen Tests dazwischen.

1Pose-Probe aus Sammy exportieren.
Die Datei heißt ungefähr Sammy_PoseProbe_Idle_Frame0048.json.
2Die Probe im Repo-Root hochladen und exakt umbenennen:
pose_probe_input.json
3Einmalig Workflow anlegen:
POSE_ORACLE_WORKFLOW.yml aus dem v0.5.24-Paket als
.github/workflows/sammy-pose-oracle.yml speichern.
4GitHub → Actions → Sammy Pose Oracle → Run workflow.
Der Workflow benutzt den gepinnten offiziellen Anny-Code und erzeugt pose_probe_oracle.json.
5pose_probe_oracle.json herunterladen und in Sammy bei Schritt 3 auswählen.

Danach zeigt Sammy zwei dicke, durch den Körper sichtbare Skelette: Gelb = Browser, Cyan = offizielles Anny. Rot/Orange markiert problematische Browser-Bones. Zusätzlich bekommst du automatisch eine numerische Diagnose.
