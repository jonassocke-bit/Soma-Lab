Regression interpretation
-------------------------
The supplied v0.8.25.0 Quick FULL fixture reproduces the exact failure mode that triggered Proof 1.1: two same-sex duplicate target pairs, zero active source variables and a 0.000 cm / 0.000 u initial Seed 1 for every round-trip. The v1.1 source contains hard pre-solver guards for all of these conditions and uses a new proof schema so the old run cannot be resumed as a v1.1 proof.

Runtime limitation
------------------
A complete Sammy mesh/pose/10-MeasurementState solve cannot be executed in this build container because normal Sammy boot depends on external Three.js / SOMA-X / Hugging Face resources. The first authoritative runtime check remains LAB -> SOLV -> Quick. Proof 1.1 is designed to stop as PROOF INVALID before solver scoring if target/seed validity is still defective.
