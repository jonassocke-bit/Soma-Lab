Runtime limitation
------------------
A full browser/model execution is not available in this offline build container
because normal Sammy boot uses external model/CDN assets. The first real-device
runtime validation therefore remains Quick on the deployed app. Direction C is
instrumented in FULL JSON with trigger, pool IDs, selected IDs, fresh column
scores, pass improvements and stop reason so runtime behavior is inspectable.
