Einmalig: Current Rig-Pack bauen

Der aktuelle NVIDIA-Rig liegt als 329-MB Git-LFS-USD vor. Er soll nicht auf dem iPhone verarbeitet oder dauerhaft geladen werden. Deshalb lässt du GitHub Actions ihn genau einmal serverseitig in den kleinen Browser-Pack umwandeln.

  1. Die Dateien aus SOMA_BROWSER_POC_V0.2.0.zip zuerst wie gewohnt ins Soma-Lab-Repo laden.
  2. GitHub öffnen → Actions → New workflow → set up a workflow yourself.
  3. Den Standardinhalt komplett markieren und durch den unten kopierten Workflow ersetzen. Dateiname z. B. build-soma-rig-pack.yml. Committen.
  4. Unter Actions den Workflow Build SOMA Current Rig Pack öffnen → Run workflow.
  5. Nach erfolgreichem Lauf liegen soma_current_rig_pack_v0026.npz und die JSON-Prüfsumme automatisch im Repo. Danach zurück zu Soma-Lab und Current Rig-Pack laden & prüfen.
